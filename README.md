## Project description

This is a project for Medica interview. It is a dashboard for viewing, creating and updating reservations.

It uses Nextjs as the framework and Tailwind and Shadcn for styling and components.

It uses zustand as a state manager for managing client side reservations.

It uses react day picker for date picker.

## Gettin started

### Install dependencies

```
npm install --legacy-peer-deps
```

### Start dev server

```
npm run dev
```

### Check production build

```
npm run build

npm start
```
